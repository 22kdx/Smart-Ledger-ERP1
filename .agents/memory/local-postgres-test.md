---
name: PostgreSQL الاختباري المؤقت
description: ملاحظة تشغيلية عند بدء نسخة PostgreSQL محلية مؤقتة داخل بيئة Replit.
---

عند تهيئة PostgreSQL مؤقت للاختبارات، لا تفترض وجود مجلد Unix socket الافتراضي `/run/postgresql`. وجّه مسار socket إلى مجلد داخل مساحة الاختبار المؤقتة.

**Why:** الخادم المحلي فشل في البدء لأن مجلد `/run/postgresql` غير موجود، رغم نجاح تهيئة مجلد البيانات.

**How to apply:** عند تشغيل نسخة اختبار مؤقتة فقط، اجعل ملفات socket وسجل الخادم داخل مجلد الاختبار المؤقت، ثم أوقف الخادم واحذف المجلد بعد الاختبار. لا تستخدم هذه النسخة بدل قاعدة VPS أو قاعدة بيانات دائمة.
