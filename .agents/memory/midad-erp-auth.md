---
name: مصادقة مدار ERP
description: قرار المصادقة القابل للنقل إلى VPS مع الحفاظ على عزل بيانات المنشآت.
---

اعتمد OIDC قياسيًا مع مزود هوية يملكه المستخدم؛ التوصية الأولية هي Keycloak مستضاف على VPS المستخدم. لا تعتمد على Clerk المُدار عبر Replit. تطبيق الجوال يستخدم Authorization Code مع PKCE، ويتحقق API من توقيع JWT والجهة المصدرة والجمهور عبر JWKS الخاصة بالمصدر. استخدم `sub` كمُعرّف المستخدم، ثم افحص عضويته ودوره للمنشأة على الخادم؛ لا تثق بمعرّف المنشأة أو الدور المرسل من التطبيق.

مكتبات Clerk ووسيط Clerk الموجودان في المشروع غير موصولين بتدفق تسجيل دخول فعلي. لا تحذفهما قبل إكمال ترحيل واضح والتحقق منه.

**Why:** التطبيق يجب أن ينتقل إلى VPS المستخدم دون الاعتماد على خدمة مصادقة خاصة بـReplit، كما أن هوية المستخدم يجب ألا تتجاوز عزل المنشآت.

**How to apply:** عند تنفيذ المصادقة، جهّز مصدر OIDC وعنوانه وعميل الجوال، وخزّن إعدادات الخادم الحساسة في بيئة VPS لا في ملفات المشروع أو أسرار Replit. أضف تحقق JWT وحراسة عضوية المنشأة على API واختبارات صلاحيات قبل ربط بيانات العمل.
