---
name: مصادقة مدار ERP
description: قرار المصادقة الداخلية القابلة للنقل إلى VPS، مع منع خدمات الهوية المستضافة افتراضيًا.
---

استخدم مصادقة داخلية في API (كلمة مرور مجزّأة، وصول قصير، وتدوير refresh) مع فحص عضوية المنشأة وصلاحياتها من قاعدة البيانات. لا تستخدم Keycloak أو Clerk أو أي خدمة مصادقة مستضافة. لا تنتقل إلى Ory Kratos/Hydra إلا إذا طلب المستخدم مزوّد OIDC كاملًا لاحقًا.

**Why:** خادم VPS الحالي محدود الذاكرة؛ المستخدم رفض تكلفة JVM الخاصة بـKeycloak، ويريد امتلاك المصادقة والبيانات على خادمه.

**How to apply:** أبقِ العميل المحمول معزولًا عن تفاصيل المزود، وخزّن أسرار الخادم خارج المستودع، ولا تعتمد على الدور أو tenant الموجود في التوكن دون استعلام عضوية وصلاحية لكل مسار بيانات.
